# 后台：用户反馈、账号/游客与错误日志

实现状态：`Implemented`。验证范围：`Local code verified`（页面模板、controller、查询/写入 service 与 API）。

三个入口均要求管理员身份。反馈状态写入需要 `admin:feedback:write`，账号创建/编辑/封禁/站点变更需要 `admin:accounts:write`；游客会话和错误日志当前为管理员只读。

## 1. 用户反馈 `view=feedback`

状态：`Current`。页面只支持筛选、查看、展开和将 NEW 标记为 DONE；不支持编辑内容、删除、重新打开或直接回复用户。

### 1.1 筛选和列表

| 字段/控件 | 输入/默认/来源 | 作用 | 操作结果/边界 |
| --- | --- | --- | --- |
| 搜索 | 文本框；300ms 防抖；服务端最多使用 120 字符 | 匹配邮箱、用户显示名、主题和反馈内容 | 回到第 1 页重新请求；当前不按用户 ID 搜索 |
| 站点 | 全部、active 站点、未指定 | 按反馈 `site_id` 过滤 | 不改变用户站点 |
| 重置 | 按钮 | 清除搜索和站点筛选 | 回到第 1 页重新加载 |
| 时间 | 创建时间 | 识别提交时间 | 分日期和时分显示 |
| 状态 | NEW/DONE pill | 处理状态 | 当前页面无状态筛选器 |
| 账号 | 正式用户邮箱/内部用户 ID；游客联系邮箱 | 识别提交人或可联系游客 | 游客不创建临时账号，显示其主动填写的联系邮箱 |
| 名称 | 用户显示名；游客显示 Guest | 辅助识别提交来源 | 只读 |
| 站点 | 名称/slug/ID | 来源业务站点 | 未指定单独显示 |
| 主题 | subject | 反馈主题 | 列表可能截断，展开不修改 |
| 内容 | content | 反馈正文 | 列表截断；展开查看全文 |
| 标记已处理 | 仅 NEW 行显示 | 写入 done 状态 | 成功后刷新行；失败保留 NEW 并提示 |
| 分页 | 上一页、页码、下一页 | 每页 20 条 | 服务端单次上限 50 |

点击行或在聚焦行按 Enter/Space 展开，显示完整正文、页面路径、User-Agent、更新时间和反馈 ID。加载、接口错误、无反馈和筛选无匹配必须区分。账号管理沿用同一份 User-Agent 请求信息：正式账号显示最后一次成功登录设备，游客会话显示最近一次访问设备；只归纳设备类型、系统和浏览器，不推测具体型号。

## 2. 账号管理 `view=accounts`

状态：`Current`。页面顶部在“正式账号”和“游客会话”两张大表之间切换。游客是独立 guest session，不会创建 `users` 临时账号，也不显示头像。

### 2.1 正式账号摘要、筛选与列表

| 字段/控件 | 输入/来源 | 作用/口径 | 操作结果 |
| --- | --- | --- | --- |
| 总账号数 | KPI | 正式 `users` 数量 | 只读 |
| 创作者 | KPI | creator 账号数 | 只读 |
| 本月封禁 | KPI | 当前查询按“账号非 active 且更新时间在本月”统计，并非严格封禁事件流水 | 只读；不能当月度封禁审计 |
| 游客总数 | 顶部标签计数 | guest session 总数 | 切换游客页 |
| 账号类型 | 全部/personal/creator/admin | 服务端过滤正式账号 | 回第 1 页 |
| 站点 | 全部、active 站点、未指定 | 按正式账号 `site_id` 过滤 | 回第 1 页 |
| 搜索 | 文本框；300ms 防抖 | 匹配用户 ID、username、nickname、email | 回第 1 页 |
| 新增账号 | 按钮 | 打开创建表单 | 成功后刷新列表 |
| 选择本页 | 按钮/行 checkbox | 选中当前页可见账号 | 用于批量操作 |
| 选择所有 | 按钮 | 请求所有匹配项，但服务端列表上限 50 | 当前实现随后只从当前 `state.items` 取批量对象，所以实际批量操作仍只作用于当前页可见且被选中的账号；计数可能显示更多。这是已知实现缺口 |
| 清除选择 | 按钮 | 清空选中 ID | 批量按钮恢复禁用 |
| 批量修改站点/身份/封禁 | 按钮 | 对当前有效选中对象执行 | 身份和封禁逐账号请求，可部分失败；站点使用批量接口 |

| 列 | 内容/交互 |
| --- | --- |
| 账号 | checkbox、头像、昵称/用户名；点击展开 |
| 邮箱 | 登录邮箱，只读列表字段 |
| 所属站点 | 站点标签或未指定 |
| 身份 | personal/creator/admin 的显示标签 |
| 状态 | active/banned |
| 注册时间 | `created_at` |
| 封禁/解封 | 行操作；当前管理员不能封禁自己 |

### 2.2 正式账号展开详情

| 分组 | 字段 | 作用 |
| --- | --- | --- |
| 基础信息 | 用户 ID、所属站点、来源页面、注册时间、最后活跃、最后登录设备、账号状态、状态备注 | 账号身份、来源和风控审计；来源页面取最近一次已承接游客会话的已验证来源；设备只归纳设备类型、系统和浏览器 |
| 资产信息 | 用户余额、充值/赠送积分余额、累计充值、累计消耗等当前统计 | 只读运营数据，不在此调整余额 |
| 使用信息 | 总对话数、近 7 日对话、已激活角色、已创建角色 | 只读使用摘要 |
| 操作 | 查看对话、编辑资料、重置密码、封禁/解封 | 打开对应弹窗或执行状态写入 |

### 2.3 新增、编辑和安全操作字段

| 模式/字段 | 控件/输入 | 必填/默认/允许值 | 校验与错误 | 保存效果/关联目标 |
| --- | --- | --- | --- | --- |
| 新增：邮箱 | email 输入框 | 服务端必填 | 转小写；必须格式合法且唯一 | 创建登录身份；后台创建时标记邮箱已验证 |
| 新增/编辑：昵称 | 文本框 | 必填；最多 64 字符 | 合并多余空白；空值拒绝 | 用户显示名 |
| 新增/编辑：身份 | 下拉 personal/creator/admin | 新增默认按 UI 当前值 | 当前管理员不能把自己降为非 admin | 更新账号权限类型；creator 仍需站点/角色业务校验 |
| 新增：密码 | password | 至少 8 位，且包含字母和数字 | 与确认密码不一致或强度不足拒绝 | 写入密码 hash，不回显 |
| 确认密码 | password | 必须与密码一致 | 仅校验，不单独存储 | 创建账号 |
| 编辑：邮箱 | 只读 | 不可修改 | 页面不提供改邮箱流程 | 维持登录身份 |
| 重置密码 | 独立弹窗：新密码、确认密码 | 同创建密码规则 | 失败不关闭弹窗 | 修改目标 hash；重置他人密码时清除其 auth token/session，重置自己时保留当前登录 token |
| 站点 | 批量站点选择：active 站点或未指定 | 服务端实际只校验站点存在，未强制 active；UI 只列 active | 非法 ID 拒绝 | 更新 `site_id` 并同步前台激活关系 |
| 封禁 | 行/批量确认 | active → banned | 不允许封禁当前管理员；写备注“后台手动封禁”并清除目标 token | 阻止后续登录和受保护操作 |
| 解封 | 行操作 | banned → active | 服务端校验账号 | 恢复账号状态；之前 token 已被清除，用户需重新登录 |

### 2.4 批量修改弹窗

| 字段/控件 | 输入/默认/来源 | 用途 | 校验与结果 |
| --- | --- | --- | --- |
| 标题与说明 | 只读；由批量站点、身份或状态动作决定 | 说明将影响当前有效选中账号 | 页面显示选中数量仅供确认，实际仍以提交时有效对象和服务端校验为准 |
| 目标站点 | 条件下拉 | 批量修改站点时选择 active 站点或未指定 | 服务端只校验站点存在；成功后同步账号 `site_id` 与前台激活关系 |
| 目标身份 | 条件下拉 personal/creator/admin | 批量修改账号类型 | 当前管理员不能把自己降为非 admin；逐账号执行时可能部分失败 |
| 目标状态 | 条件下拉 active/banned | 批量封禁或解封 | 不允许封禁当前管理员；封禁清除目标 token |
| Confirm | 主按钮；文字随动作变化 | 提交批量修改 | 弹窗先关闭，再执行实际请求；结果用成功/失败提示反馈 |
| Cancel / X / scrim | 关闭控件 | 放弃本次批量修改 | 不提交请求，不清除当前账号勾选状态 |

### 2.5 正式账号对话记录

状态：`Current / Read-only`。先列出账号会话并按角色展示最近消息和用户消息数，再打开单个会话查看文本、商品、图片和附件消息。单次详情最多返回最近 200 条并提供 `hasMore` 提示；不允许从后台改写或删除消息。

| 字段/控件 | 输入/来源 | 用途 | 结果与边界 |
| --- | --- | --- | --- |
| 标题/账号摘要 | 当前昵称或邮箱、会话数量 | 确认正在审计哪个账号 | 只读，不允许从弹窗切换目标账号 |
| 搜索角色、对话关键词 | 文本输入 | 在已加载会话中筛选角色或消息内容 | 只影响当前列表，不修改聊天数据 |
| 会话行 | 角色头像、名称、定位、日期、最近消息和消息统计 | 选择要查看的会话 | 点击进入只读详情 |
| Back | 详情页按钮 | 返回该账号会话列表 | 保留当前弹窗，不进入账号主表 |
| 消息线程 | 最近文本、商品、生成图片和附件消息 | 审计会话内容 | 不提供编辑、删除、重发或下载全部数据 |
| 历史截断提示 | `hasMore=true` 时显示 | 提醒只返回最近 200 条 | 当前正式账号模板文字误写为“游客消息”，属于显示文案缺口，不改变实际查询归属 |
| Close / scrim | 关闭控件 | 退出对话审计 | 不改变会话、消息或账号状态 |

### 2.6 游客会话摘要与列表

| 字段/控件 | 输入/来源 | 作用/口径 |
| --- | --- | --- |
| 有效游客 | KPI | 当前 active、未撤销且未过期的 guest session |
| 今日参与聊天 | KPI | 今天存在用户消息或开始过实时通话的 guest session 去重数 |
| 今日转注册 | KPI | 今天 claim 完成的 guest session 数 |
| 状态 | 全部、活跃中、额度已满、已转注册、已过期 | `claiming`/异常状态只能在“全部”中出现 |
| 站点 | 全部或 active 站点 | 按冻结 `site_id` 过滤 |
| 搜索 | 最多 160 字符 | 匹配 guest ID、站点名称/slug、前台名称，以及承接账号邮箱/用户名/昵称 |
| 游客会话 | 完整/短 guest ID | 浏览器 cookie 对应身份；无头像、无临时账号 |
| 站点 | 冻结 site | 不会因默认站点/IP 改写 |
| 前台 | 冻结 mascot | 只读 |
| 消息/商品 | 用户消息数与商品消息数 | 只读累计；滚动额度另见展开详情 |
| 自拍资格 | available/reserved/consumed/缺失或异常 | 只读状态机 |
| 状态 | active/limit/claimed/expired/claiming/异常 | 服务端实时派生 |
| 最后活跃 | 最近活动时间和承接摘要 | 只读 |

### 2.7 游客展开详情与对话

| 分组 | 字段/规则 |
| --- | --- |
| 基础 | guest ID、站点、前台、来源页面、创建/最后活跃、最近访问设备、原始状态；来源页面来自已验证的 `external_source_context_json`，没有来源的历史会话显示 `-` |
| 使用 | 语音输入数、附件数、商品消息数、实时通话次数/时长/回合、自拍资格 |
| 额度 | 当前滚动 24 小时已用条数/30；超过 24 小时的旧条数不计当前 quota |
| 有效期 | 服务端实际 `expires_at`；后台不硬编码“14 天”文案 |
| 认证承接 | claim 状态、正式账号、claim 时间；没有跨设备游客恢复 |
| 查看对话 | 最近最多 200 条游客阶段原始消息；按 `chat_messages.display_order` 对齐聊天显示顺序，再以发送时间和消息 ID 稳定排序；只返回匹配 `guest_session_id` 的消息，不返回 cookie、token hash 或 claim secret |

游客状态派生顺序：已 claim 显示 converted；过期/撤销/cleanup pending 显示 expired；处理中显示 claiming；有效且滚动额度达到 30 显示 limit；其余有效会话显示 active。claim 后正式账号的新消息不会混入游客审计弹窗。

## 3. 错误日志 `view=logs`

状态：`Current / Read-only`。页面合并 AI 回复异常与应用 warning/error/critical 日志，当前不显示 INFO。

### 3.1 筛选和列表

| 字段/控件 | 输入/默认/来源 | 查询规则/结果 |
| --- | --- | --- |
| Level | 全部异常、Error、Warn | AI fallback/error/quality_warn/quality_block 与应用 warning/error/critical 映射为显示等级 |
| 开始日期 | 原生 date，可空 | 服务端从当日 00:00:00 起（含）查询 |
| 结束日期 | 原生 date，可空 | 服务端以次日 00:00:00 为上界（不含），因此包含所选结束日全天 |
| Source | 动态来源下拉 | 来源于当前日志 facets，例如 AI reply、app/client 等 |
| 重置 | 按钮 | 清空筛选并回第 1 页 |
| 日期 | 只读 | 统一页面时间格式 |
| Level | 只读标签 | error/warn |
| 报错内容 | 只读摘要 | AI 日志显示模型、状态、耗时和原因；应用日志显示 type/status/endpoint/reason |
| Source | 只读 | 原始日志来源类别 |
| 分页 | 上一页/页码/下一页 | 页面每页 20；服务端上限 100 |

当前服务端没有显式拒绝“结束日期早于开始日期”，这种组合通常返回空结果；页面不能把它描述为已完成校验。应用错误写入会对 authorization/key/token/secret/password 等敏感模式脱敏，并限制 message、stack、context 长度；后台表格只展示净化后的摘要，不展示密钥或完整敏感 payload。脱敏是服务端安全边界，不能只依赖前端隐藏。

加载中、无日志、筛选无结果和接口失败必须分别显示。接口失败不能显示成“暂无错误”。
