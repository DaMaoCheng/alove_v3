# 后台：站点、前台与首页轮播

实现状态：`Implemented`。验证范围：`Local code verified`（页面模板、controller、service、数据库写入与 API 路由）。

入口分别为 `/admin?view=sites`、`/admin?view=mascot`、`/admin?view=carousel`，均要求管理员身份；写入还分别要求 `admin:sites:write`、`admin:mascot:write`、`admin:carousel:write`。手动发送广告使用 `admin:promotions:write`。

## 1. 站点管理 `view=sites`

状态：`Current`。站点是用户、商品、前台、活动和运营数据的业务归属，不等同国家或语言。内部关系使用稳定 `site_id`；slug 用于 `/:siteSlug/*` 用户路径。

### 1.1 列表字段和操作

| 字段/操作 | 来源/输入 | 作用 | 点击结果/边界 |
| --- | --- | --- | --- |
| 全部站点 | 顶部分段标签 | 当前只是固定的页面标题状态 | 不是可切换筛选器 |
| 站点 | 名称、网站链接、默认标记 | 识别站点 | 有网站链接时可打开独立站 |
| 路径 | slug | 显示用户 URL 前缀 | 只读列表字段 |
| 目标地区 | 地区绑定 | 最多展示部分标签及剩余数量 | 用于 Geo/IP 候选，不覆盖显式有效路径 |
| 用户数 | 站点用户统计 | 运营参考 | 不等于手动广告的最终可发送人数 |
| 前台 | 有效 mascot 名称/ID | 显示该站点当前前台 | 可能来自专属设置或通用模板 fallback |

| API 版本 | 当前只读标签/隐藏字段 | 无合法现值时使用配置默认值；当前 UI 显示 `2026-04` | 必须符合 `YYYY-MM`，否则回落服务端默认 | 决定 Shopify Admin API 版本 | Shopify |

| 说明 | textarea | 可空；最多 500 字符 | 超长按服务端限制 | 运营备注，不参与路由/权限 | 后台运营 |

`site_status` 和 `is_default` 虽由服务端数据模型支持，但当前站点编辑弹窗没有状态/默认字段：新建默认 active，设默认必须用列表独立按钮。编辑当前正在访问站点的 slug 后，同一页面不会立即改写浏览器旧路径；刷新后由显式路径校验进入真实站点，外部旧链接仍需运营同步更新。敏感 token 不得进入普通 API 响应、浏览器日志、截图或设计文档。

公开品牌只通过 `/api/site/branding?siteSlug=<slug>` 返回名称、slug、网站链接和 Logo。Logo 留空时按网站 favicon、可信商品公开 URL favicon、globe 顺序回退；该接口不会返回商品源、token、Admin 域名、地区或运营备注。

## 2. 前台管理 `view=mascot`

状态：`Current`。页面维护一套通用前台模板、站点专属前台 override 和尚未绑定站点的 mascot。使用通用模板 fallback 的站点不会逐行出现在“各站细分”表中；该表只列专属 override 与未绑定前台。

### 2.1 通用模板与列表

| 区域/字段 | 来源与意义 | 操作 |
| --- | --- | --- |
| 通用模板 | 模板头像、名称、问候语、知识摘要 | “编辑模板”更新 `mascot_template`，供无专属前台站点 fallback |
| 前台 | 头像、名称、ID | 编辑当前前台 |
| 绑定站点 | 站点名称/slug | 未绑定前台显示 `-` |
| 默认语言 | 站点语言 | 只读 |
| 知识库 | 当前知识绑定摘要 | 只读；到知识库页维护 |

| 已发广告 | 至少成功发送给 1 名用户的手动投放任务数 | 只读；全失败或 0 目标任务不计数。页面轮询观察到任务终态且 `sent > 0` 时当前行立即 +1，刷新后由服务端统计校准 |

| 字段 | 控件/输入 | 必填/默认/允许值 | 校验/错误 | 保存效果 | 关联目标 |
| --- | --- | --- | --- | --- | --- |
| Avatar | 上传、AI 生成、删除 | 复用角色头像策略 | 上传/生成失败保留当前图片 | 更新前台头像 | 左侧通讯录、聊天、Discover guide 卡 |
| 名称 | 文本框 | 必填；最多 96 字符 | 空值拒绝 | 更新前台名称 | 用户页面 |
| 绑定站点 | 下拉；已有站点 override 固定当前站点 | 新建或未绑定前台可选，也允许暂不绑定 | 同一站点已有专属前台时拒绝重复绑定 | 建立 `site_id` 和站点默认 mascot 引用 | 站点、聊天 |

| 人设 | textarea，10 行 | 可空；最多 12,000 字符 | 保存错误显式提示 | 仅在内容被编辑时写入绑定角色的 `ai_characters.persona_prompt` | AI 回复 Persona 层 |
| 语气 | textarea，4 行 | 可空；最多 12,000 字符 | 保存错误显式提示 | 仅在内容被编辑时写入绑定角色的 `ai_characters.speaking_style`，并同步 `profile_json.style` | AI 回复 Speaking Style 层 |
| 问候语 | textarea | 可空；最多 512 字符 | 超长拒绝/限制 | 更新前台开场问候 | 新会话/首页 |
| 问候素材库 | 固定 5 个槽位：前 4 个为图片、第 5 个为视频；空槽点击上传、缩略图点击放大/播放、右上角删除 | 仅已保存且已发布的前台可维护；图片支持 JPG/PNG/WebP，上传后立即缩放并转为 WebP；视频仅支持源文件不超过 30MB 的 MP4，上传后立即压缩为 H.264/AAC MP4 | 非管理员、非前台角色、非法槽位、槽位媒体类型不符、非法 MIME/超大上传、压缩失败均由服务端拒绝且不保存原文件 | 新建前台会话在文字问候后优先发送 ready 视频；没有视频时由服务端安全随机数选择一张 ready 图片；没有任何素材时不创建媒体消息 | 聊天首条体验、管理员会话详情 |
| 知识库 | 当前绑定摘要与隐藏 ID | 本编辑器不作为主要绑定入口 | 不应在这里形成第二套关系 | 由知识库页统一维护 | KB retrieval |

问候素材不是用户即时生图：它们使用独立公共素材库，不占用户/游客图片额度、不进记忆或摘要任务、不进入用户图片资产和图片队列。每个会话只在文字问候成功新建时执行一次确定性优先级判断：视频优先；无视频才在当前 ready 图片中由代码随机一个数组编号。消息保存具体素材 URL 与媒体类型快照；刷新、语音重试和恢复旧会话都不会再次选择。素材删除的语义是停止未来发送，历史对话仍保留原文件以确保会话记录不破损。没有 ready 素材时只写问候文字/语音，媒体 service 返回空结果且不插入空消息。

旧 `mascot_settings.tone` 仅保留为历史配置兼容字段。前台管理不再用它回填或覆盖真实角色人设；当管理员只修改头像、名称、问候语或知识库时，角色的 `persona_prompt`、`speaking_style` 与 `profile_json` 保持原样。

### 2.3 手动发送广告

状态：`Current`。该功能发送已保存的广告活动，不在弹窗内临时编写广告。

| 字段/状态 | 输入/来源 | 校验与结果 | 关联目标 |
| --- | --- | --- | --- |
| 标题附注 | `站点名称 / 用户数` | 用户数来自站点汇总，只用于提示；真正 `total` 在创建任务时按资格重新计算 | 当前站点 |
| 广告活动 | 下拉单选 | 只列同站点、站点 active、活动 `active`、当前时间已开始且未结束、角色范围为 all/mascot、并存在有效 published 前台的活动 | 广告活动 |
| 发送 | 按钮 | 创建持久化任务；同站点同活动存在进行中任务时返回该任务，避免重复创建 | 后台投放任务 |
| 排队/发送中 | 进度文字 `processed / total` | 页面约每秒轮询；`processed = min(total, sent + failed)` | 投放进度 |
| 完成 | 成功数、失败数 | 0 目标也会直接完成；失败是逐目标真实结果；存在失败时显示圆形 `?`，鼠标悬停或键盘聚焦后展示按原因归类的人数 | 活动 delivery、当前行“已发广告” |
| 关闭 | 按钮/X | 只停止当前页面轮询，不取消后台任务 | 后台任务继续 |

任务目标必须同时满足：正式账号 active、账号与前台属于同一站点、已激活当前前台、存在该前台的正式 active chat session。游客、无会话用户和其他站点用户不进入任务。手动广告不检查或消耗自动主动消息额度，也不受“上一条主动消息尚未回复”门禁影响；仍执行活动有效性复核和投放去重。失败明细只返回脱敏后的原因分类和人数，不返回用户身份或底层异常原文。轮询连续失败只表示页面暂时无法确认状态，不能据此认定后台任务已停止。

关闭发送弹窗会按既有规则停止该弹窗轮询，因此后台任务在关闭后才完成时，当前页面的“已发广告”不会主动变化；重新进入前台管理或刷新页面后按服务端真实统计显示。该边界不影响后台任务继续执行。

## 3. 首页轮播 `view=carousel`

状态：`Current`。页面管理 Discover 首页 banner 列表；前端只读取符合站点、published 和排期条件的条目，并按 `display_order` 升序、更新时间降序排列。

### 3.1 列表

| 列/操作 | 作用 |
| --- | --- |
| 图片 | banner 预览 |
| 标题/副标题 | 识别轮播内容 |
| 站点 | 指定站点或全部站点 |
| CTA | 目标类型与目标摘要 |
| 排序 | `display_order`，小值优先 |
| 状态 | draft/published/archived |
| 编辑 | 打开弹窗；当前没有删除操作 |

### 3.2 编辑字段

| 字段 | 控件/输入 | 必填/默认/允许值 | 校验与错误 | 保存/展示效果 |
| --- | --- | --- | --- | --- |
| 图片 | 上传并裁剪 16:9 | 必填；接受轮播上传策略 | 保存时才提交上传；失败保留编辑状态 | banner 背景图 |
| 标题 | 文本框 | 必填；最多 128 字符 | 空值拒绝 | 主标题 |
| 小标签 | 文本框 | 可空；最多 64 字符 | 超长受限 | eyebrow 文案 |
| 绑定站点 | 下拉 | 可空；空表示全站点 | 当前服务端未校验 site 是否真实存在，是已知缺口 | 决定站点过滤 |
| 描述 | textarea | 可空；最多 500 字符 | 超长受限 | 副标题 |
| 按钮文字 | 文本框 | 可空；最多 64 字符 | 没有有效 CTA 时前端可不显示按钮 | CTA label |
| 点击类型 | 下拉：none/character/url | 默认 none | 当前服务端没有按类型强制目标必填 | 决定跳转模式 |
| 角色目标 | mascot/creator 搜索选择 | 仅 character 时显示；指定站点后 UI 只给该站点 creator 与有效 mascot | UI 过滤不是服务端引用完整性保证，当前后端仍有校验缺口 | 进入角色聊天 |
| URL 目标 | 文本框 | 仅 url 时显示；最多 512 字符 | 当前服务端未强制 http(s)，前端安全打开仍需防护 | 跳转外链 |
| 排序 | number | 0–9999，默认 100；服务端取整/限幅 | 非法值回到规范值 | 数字越小越靠前 |
| 状态 | 下拉 | draft/published/archived；默认 draft | 直接保存状态 | 仅 published 参与前端查询 |

数据模型支持 `startsAt/endsAt`，当前弹窗没有这两个字段；不能在文档或运营说明中声称可在此配置排期。

| 16:9 画布 | 鼠标/触摸拖动 | 打开时按图片尺寸自动填满裁剪框 | 调整 Banner 取景 | 拖动受边界限制，不允许露出空白 | 只更新本地裁剪位置 |
| Zoom | range 滑杆 | 1–3，步进 0.01 | 放大 Banner 取景 | 基于最小填满比例缩放 | 只更新本地缩放值 |
| Use image | 主按钮 | 当前裁剪结果 | 确认轮播图 | Canvas 转换失败显示明确错误并保留编辑器 | 生成 16:9 WebP 待上传数据；真正上传发生在保存轮播时 |
| Cancel / X / scrim | 关闭控件 | 固定行为 | 放弃本次裁剪 | 不覆盖编辑器已有图片 | 关闭裁剪器，不保存本次候选 |

裁剪成功只表示页面拿到待提交图片，不等于轮播已保存；随后保存弹窗时仍可能因上传、权限或轮播字段校验失败，失败时应保留当前编辑内容。
