# 后台：静态待办与隐藏入口

实现状态：`Placeholder / Hidden`。验证范围：`Local code verified`（导航、静态模板与 view 归一化逻辑）。

本页只记录现有 UI 表面和未来职责边界，不代表功能已实现。`leads`、`payments`、`costs` 虽出现在后台导航，但当前没有真实 controller/service/API/数据库写入；折扣码已迁移到 [06-discount-codes.md](./06-discount-codes.md)；`agents` 不在导航白名单。任何仍保留的静态数字、表格行、按钮、输入框都不能用于真实运营。

## 1. 总览

| 入口 | 状态 | 当前可见字段/控件 | 当前点击/输入结果 | 禁止误解 |
| --- | --- | --- | --- | --- |
| `view=leads` | Placeholder | 意向分段、添加线索、公司/类型/意向/交易额/添加时间/查看 | 仅静态 UI，无新增、筛选、详情或保存 | 不能录入客户资料，不能统计真实商机 |
| `view=payments` | Placeholder | 月流水、退款率、客单价 KPI，订单/用户/商品/金额/状态 | 仅静态 UI，无支付数据源 | 静态金额不能用于财务或对账 |
| `view=costs` | Placeholder | 对话预算、每日上限、ROAS 止损、保存，利润摘要 | 输入不持久化，“保存”无真实效果 | 不构成限额、成本控制或利润模型 |
| `view=agents` | Hidden | 遗留角色卡模板/controller | URL 会被归一化回 overview | 不是可访问角色管理页 |

这些页面仍受 admin shell 保护，但“需要管理员才能看见静态页”不等于已经存在真实权限、业务规则或数据安全链路。

## 6. AI 角色卡 `view=agents`

状态：`Hidden / Legacy`。代码中保留了看似完整的模板和 controller，并可能复用部分角色 API；但该 key 不在 `ADMIN_NAV`，`normalizeAdminView()` 会把手工 URL 归一化为 overview。因此：

- 用户没有受支持的页面入口；
- 不能把遗留模板字段写成现行功能；
- 不应通过浏览器手工调用 controller 作为运营流程；
- 若未来恢复，必须先决定它与“网红角色”“通用角色”“前台管理”的职责，避免第四套角色编辑真相。

遗留模板仍包含以下字段，仅用于代码盘点，不代表可运营能力：

| 字段/控件 | 遗留输入方式 | 模板行为 | 当前边界 |
| --- | --- | --- | --- |
| 搜索角色名称 | 文本框 | 在旧角色列表中筛选 | 无可达页面，不作为支持的搜索入口 |
| 角色列表 | 头像、名称、ID、定位、风格、发布状态 | 选择左侧角色加载旧编辑器 | 列表模板保留，但后台路由不会进入该 view |
| 头像地址 | URL 文本框，最多 512 字符 | 直接编辑头像 URL | 绕过当前受控上传/裁剪规范，恢复前必须移除或加固 |
| 角色 ID | 只读输入框 | 显示稳定 ID | 不可修改 |
| 角色名称 | 必填文本，最多 96 字符 | 修改显示名称 | 与通用/网红角色管理重复 |
| 角色定位 | 文本，最多 128 字符 | 修改 role title | 与通用角色编辑器重复 |
| 分类 | 下拉 | Football Babe、Creator、Pundit、Fan、Companion 映射 | 遗留链路未按当前管理域拆分 mascot/creator 边界 |
| 发布状态 | 下拉 | draft/published/archived | 模板允许直接修改 |
| 可见性 | 下拉 | public/private | 模板允许直接修改 |
| 短简介 | textarea，最多 255 字符 | 修改角色卡简介 | 与现行编辑器字段来源可能冲突 |
| 性格 | 受控下拉 | 旧 Create personality 列表 | 修改角色私有人设字段 |
| 声音 | 受控下拉 | 旧 Create voice label 列表 | 只保存旧映射值，不能据此认定 provider 可用 |
| 默认语言 | 旧文本字段，最多 128 字符 | 仅属于不可达遗留角色编辑页 | 现行站点管理已使用受控语言库；不得恢复此字段作为站点语言来源 |
| 语音 ID | 只读 | 显示内部已有 voice ID | 不允许编辑，但也不应对普通运营暴露内部映射 |
| 开场白 | textarea，最多 512 字符 | 修改 opening line | 与现行角色编辑器重复 |
| 背景故事 | textarea | 修改 persona prompt | 与现行角色私有设定重复 |
| 保存设置 | 主按钮 | 旧 controller 尝试调用角色更新链路 | 因 view 不可达而不属于受支持流程；禁止以手工触发作为验收 |

如未来决定删除该遗留页面，应同时删除对应模板/controller 并更新本页；如决定恢复，则必须先写功能规格、统一字段来源和权限，再迁入现行角色管理域，不能直接开放 `agents` 路由。

## 8. 未来启用的固定要求

1. 先更新对应 `docs/design/` 长期产品规则并标注 `Approved direction` 或 `TBD`。
2. 编写独立功能规格：目标、非目标、字段、输入方式、状态机、权限、数据源、错误、审计与验收。
3. 实现真实 controller/service/API/数据库和服务端权限，不能只让按钮“有反应”。
4. 用真实空态、失败态、权限态和端到端链路验收后，才把状态改成 `Current`。
5. 清除所有静态示例数据，避免与线上真实统计混合。
