# 后台：概览与角色管理

实现状态：`Implemented`。验证范围：`Local code verified`（页面模板、controller、service 与 API 路由）。

所有页面入口均为 `/admin?view=<key>`，必须先通过 `requireAdmin()`。读取能力面向管理员；创建、编辑、上架、归档等写操作还需要 `admin:characters:write`。当前没有后台权限配置页面：普通管理员是否能写由服务端 scope 决定，配置中的 super admin email 拥有全部写 scope。隐藏按钮不构成权限边界。

## 1. 概览 `view=overview`

状态：`Current local`。页面目标是查看正式账号从对话商品、Search 商品结果和 Kitshop 货架进入的曝光、点击、详情打开和 Buy now 跳转漏斗，以及按入口拆分的商品表现排行；它不是用户、收入、对话量等全业务总览。游客商品浏览不写入正式用户 analytics，因此不在本页统计。

### 1.1 筛选、指标与操作

| 字段/控件 | 输入方式 | 必填/默认/来源 | 作用与口径 | 点击或变更结果 | 关联目标 |
| --- | --- | --- | --- | --- | --- |
| 时间范围 | 分段单选：今天、7 天、30 天 | 默认 7 天 | 限定统计窗口 | 重新请求 KPI 与商品排行，分页回到第一页 | 商品消息事件统计 |
| 站点 | 下拉单选 | 全部站点或 active 站点；默认全部 | 按事件所属 `site_id` 限定数据 | 重新请求，不修改管理员或用户站点 | 站点管理 |
| 商品曝光 | KPI，只读 | 服务端统计 | 三个入口中商品卡实际渲染次数之和 | 无操作 | 商品漏斗 |
| 商品点击 | KPI，只读 | 服务端统计 | 三个入口中用户打开商品详情的卡片点击次数；附点击率 | 无操作 | 商品漏斗 |
| 详情打开 | KPI，只读 | 服务端统计 | 商品详情面板实际打开次数；附打开率 | 无操作 | 商品详情 |
| Buy now 跳转 | KPI，只读 | 服务端统计 | 用户点击外部购买入口次数；附跳转率 | 无操作 | 独立站商品页 |
| 入口拆分 | 三张只读卡：对话商品、搜索结果、Kitshop 货架 | 服务端按可信入口归属聚合 | 每张显示曝光、点击、详情、跳转及点击率/跳转率 | 无操作 | 对话、Search、Kitshop |
| 商品搜索 | 文本框 | 可空；匹配标题、URL、站点 slug 或站点 ID | 只过滤当前已经加载的商品排行 | 不发起商品搜索、不修改缓存 | 当前排行表 |
| 排序 | 点击可排序表头 | 默认按商品点击数降序 | 支持商品、入口、站点、曝光、点击、CTR、详情打开、跳转、跳转率 | 再次点击切换升/降序 | 当前排行表 |
| 分页 | 上一页、页码、下一页 | 每页 10 条 | 对排序和搜索后的结果做客户端分页 | 切换当前页 | 当前排行表 |

### 1.2 排行表字段

| 列 | 数据来源与用途 | 交互/异常 |
| --- | --- | --- |
| 商品 | 可信事件快照中的商品标题 | 有安全 URL 时标题可在新窗口打开；无 URL 时仅显示文本 |
| 入口 | `chat`、`search` 或 `kitshop` | 同一商品在不同入口分别成行，不混淆来源 |
| 站点 | 事件对应站点名称/slug | 未绑定时按页面空值格式显示，不推断默认站点 |
| 曝光 | 当前入口商品卡曝光次数 | 缺失按 0 |
| 点击 | 当前入口打开详情的点击次数 | 缺失按 0 |
| CTR | 点击数/曝光数 | 分母为 0 或历史数据缺少同口径曝光时显示 `—`，不展示超过 100% 的伪比率 |
| 详情打开 | 商品详情打开次数 | 缺失按 0 |
| 跳转 | 跳转独立站商品页次数 | 缺失按 0 |
| 跳转率 | 跳转/详情打开 | 分母为 0 或历史数据缺少同口径详情时显示 `—` |

页面必须区分整页加载、接口失败、暂无统计数据和搜索无匹配四种状态；接口失败不能以全 0 伪装成功。

## 2. 网红角色 `view=creatorCharacters`

状态：`Current`。页面用于管理与 creator 正式账号一一绑定的公开角色。角色从 owner 账号继承 `site_id`，不能在角色编辑器里跨站手改；一个 creator 账号只能拥有一个未归档的网红角色。

### 2.1 列表、筛选和操作

| 字段/控件 | 输入/来源 | 作用 | 操作结果/边界 |
| --- | --- | --- | --- |
| 站点筛选 | 全部站点或 active 站点 | 在已加载角色中按 owner 的 `site_id` 过滤 | 不更改角色站点 |
| 搜索 | 文本框 | 服务端按角色名称、角色 ID、绑定账号信息匹配 | 刷新列表；错误显示在列表区 |
| 新建网红角色 | 按钮 | 打开创建弹窗 | 仅写 scope 可保存 |
| 角色 | 头像、名称 | 识别角色 | 编辑入口打开同一角色 |
| 角色 ID | 服务端稳定 ID | API、会话和绑定关系使用 | 只读，不能重写 |
| 对应账号 | creator 昵称/邮箱 | 显示 owner | 编辑后仍不可换绑 |
| 所属站点 | owner 的站点 | 决定发现、聊天和数据边界 | 账号未绑定 active 站点时不能作为新建候选 |
| 状态 | published/archived 等 | 表示是否可继续公开使用 | 行操作可上架/归档；服务端最终校验 |
| 知识库 | 绑定摘要/入口 | 只读展示 | 绑定在知识库页面维护 |
| 对话数 | 统计 | 运营参考 | 无数据按 0/空值显示，不填假数据 |
| 收入 | 当前统计字段 | 运营参考 | 只读；不构成结算依据 |

列表加载中、接口失败、无角色和筛选无匹配分别显示。创建/编辑失败必须保留当前输入与错误提示，不能直接关闭弹窗。

### 2.2 新建与编辑字段

| 字段 | 控件/输入内容 | 必填/默认/允许值 | 校验与错误 | 保存效果 | 关联目标 |
| --- | --- | --- | --- | --- | --- |
| Avatar | 上传、AI 生成、删除 | JPG/PNG/WebP；源文件最大 12MB；产出 512×512 WebP | 不支持类型、超限、处理或生成失败时提示且不保存错误资源 | 更新角色头像 | Discover、通讯录、聊天 |
| 角色名称 | 文本框 | 必填；最多 96 字符 | 空值由服务端拒绝 | 更新公开显示名称 | 角色卡与聊天 |
| 绑定账号 | creator 账号搜索选择；编辑时只读 | 新建必填；候选必须 active、已有 active 站点，且未绑定其他未归档网红角色 | 无候选、账号不合法或重复绑定时拒绝 | 确定 owner 与 `site_id` | 账号管理、站点 |
| 所属站点 | 只读随账号显示 | 由 owner 决定 | 不接受角色表单手改 | 固定角色业务归属 | 多站点发现/聊天 |
| 分类 | 隐藏值 | 固定 `creator` | 服务端按类型链路处理 | 保持网红角色类别 | Discover 分类 |
| 可见性 | 隐藏/只读值 | 固定 `public` | 不提供 private 切换 | 允许按站点公开发现 | Discover/Search |
| Personality | 卡片单选 | 来自项目支持项；默认当前 UI 的 Cheeky banter | 非支持值由规范化/服务端处理，页面不应自造值 | 写入角色私有设定 | AI 文本行为 |
| Voice | 预设下拉，可试听 | 必须选择已加载 voice preset | 试听失败不等于保存失败；无效 preset 不能作为有效配置 | 保存语音音色 ID | 语音回复、实时通话 |
| Language | 可搜索语言下拉 | 来自支持语言库，保存 code/label | 不接受任意伪造选项 | 更新默认回复和语音语言上下文 | Chat/TTS |
| Opening line | 文本框 | 可空；最多 512 字符 | 超长由前后端限制 | 更新会话开场白 | 新会话 |
| Backstory | textarea | 可空；最多 4000 字符 | 超长拒绝/截断规则以服务端为准 | 写入角色私有人设层 | AI prompt |
| AI 润色 | 按钮 | 需要已有上下文 | 生成失败保留原文 | 只回填 Backstory，不自动保存 | 角色编辑器 |
| 上架状态 | 下拉 | 新建默认 published；编辑提供 published/archived | 不允许绕过服务端角色规则 | published 可公开使用；archived 从新聊天入口移除 | Discover、Chat |

## 3. 通用角色 `view=commonCharacters`

状态：`Current`。页面管理非 creator、非 mascot 的角色。它们不天然绑定站点，能否跨站展示仍由角色可见性、激活关系和公开查询规则共同决定；“通用”不等于绕过账号权限或站点上下文。

### 3.1 列表字段与操作

| 字段/控件 | 作用/来源 | 操作 |
| --- | --- | --- |
| 搜索 | 按名称、ID 等当前服务支持字段筛选 | 刷新列表 |
| 角色 | 头像和名称 | 打开编辑 |
| 角色 ID | 服务端稳定 ID | 只读 |
| 创建者 | owner/创建来源 | 只读，不在该页换绑 |
| 分类 | 当前 category label | 只读列表展示，编辑器可按允许项修改 |
| 状态 | draft/published/archived 中的当前值 | public 角色可用行操作上架/归档 |
| 可见性 | public/private | 决定发现范围与 owner 边界 |
| 知识库 | 绑定摘要/入口 | 仅查看；去知识库页调整 |
| 对话数 | 统计 | 只读 |

### 3.2 新建与编辑字段

| 字段 | 控件/输入内容 | 必填/默认/允许值 | 保存效果与目标 |
| --- | --- | --- | --- |
| Avatar | 上传、AI 生成、删除 | JPG/PNG/WebP，最大 12MB，输出 512×512 WebP | 更新角色卡、聊天头像 |
| 名称 | 文本框 | 必填，最多 96 字符 | 公开/私密角色显示名称 |
| 角色定位 | 文本框 | 当前编辑时显示，最多 128 字符 | 写入 `roleTitle`，参与角色定位展示/提示词 |
| 分类 | 下拉/选择器 | 只能选择当前角色管理允许的分类 | 改变角色分类标签；不能改成 creator 或 mascot 管理域 |
| 简介 | 只读 | 当前由创建链路生成；编辑器不直接改 | 用于角色卡短介绍 |
| Personality | 卡片单选 | 仅项目支持值 | 写入角色私有行为设定 |
| Voice | 预设下拉，可试听 | 仅已加载 preset | 语音回复与通话音色 |
| Language | 可搜索下拉 | 保存支持语言 code/label | 文本与语音默认语言 |
| Visibility | 卡片：public/private | 新建默认 public | public 可进入发现/搜索；private 仅 owner 可见，并联动状态控件 |
| 状态 | 编辑时 public 角色提供 published/archived；新建默认 published | 服务端还接受 draft，但当前新建 UI 不提供；private 角色不显示上下架控件 | 控制公开入口；不是删除 |
| Opening line | 文本框 | 可空，最多 512 字符 | 新会话开场白 |
| Backstory | textarea | 最多 4000 字符 | 角色私有人设层 |
| AI 润色 | 按钮 | 有输入时使用 | 只回填 Backstory，不自动保存 |

新建时服务端还会生成/规范化 `roleTitle` 与短简介；生成或保存错误必须显式展示。上架、归档和可见性是确定性字段，不能交给模型判断。

## 4. 状态、边界与关联

- 角色归档不是物理删除；历史会话/消息是否仍可读由聊天与权限服务决定。
- creator 角色站点来源于 owner 账号；通用角色不通过该字段获得站点身份。
- 角色知识绑定只在知识库管理域维护，角色页不建立第二套绑定真相。
- 角色私有人设与全局 AI 行为规则组合方式见产品设计文档；本页字段只负责角色私有层。
- 前台 mascot 不在这两个页面维护，统一进入“前台管理”。
