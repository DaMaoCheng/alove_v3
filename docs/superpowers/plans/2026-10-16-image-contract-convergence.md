# 图片交付生成/审核规则收敛（仅本地）

用户授权通用修复并要求真实图片与自然补充文字同时通过，不影响混合及其他分流。保留当前未发布的每模型15秒分类预算。快照在.backups/image-contract-convergence-20261016/，不动已有生产或Git。

## 修改边界

1. 复用chat-image-status-context-service，增加纯函数构造本轮current ready且无not_created的交付契约。生成状态指令和审核引用同一份事实/措辞边界，来源library不等于图库界面，当前角色图交付不等于未来联系、推销或新拍摄。
2. review-contracts中按是否存在图片事实显式组装销售/联系条款，去除无条件禁止所有browsing后再补例外的矛盾；无图规则逐字不变。原IMAGE_ACTION_BOUNDARY重复段删除，图片状态/历史/失败规则仍保留。
3. generation、prompt-layer及recovery删除技术图库来源诱导和重复约束；用既有状态reader和shared交付契约。不加图片工具、重试、模板池、模型替换或审核绕过。
4. 原身份/作用域anchor、完整语言/事实/商品/订单审核、一次文字恢复和双刷新、保留段落、mixed回复保持。不能为了自然回复放行图库界面臆造或未经执行的动作。
