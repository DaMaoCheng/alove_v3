# 前台手动广告投放实施计划

## 批次 1：数据与后台任务

- 扩展 `mascot_ad_deliveries` 保存活动、总数、成功/失败、开始/完成时间。
- 新增 `mascot_ad_delivery_targets` 保存每个正式账号的会话和处理状态。
- 新增手动投放 memory job，复用现有活动消息、语音和活动去重；不接入自动主动消息额度服务。

验证：迁移幂等；活动/站点/角色/用户范围校验；重复任务和任务重放不重复消息；失败目标不占用成功记录。

## 批次 2：管理接口与前端

- 新增站点有效活动列表、启动投放、查询进度接口。
- 将已确认弹窗的静态活动和演示计数替换成真实接口与轮询。
- 保留现有标题、站点人数、按钮顺序和完成结果样式。

验证：空活动、加载失败、启动失败、发送中、完成状态正确；关闭弹窗停止轮询但不停止后台任务。

## 批次 3：全链路回归

- 以临时本地数据验证活动文本、商品消息、角色语音、delivery 和进度结果。
- 回归自动主动消息、活动匹配、前台管理、活动管理和部署检查。
- 验证完成后更新设计状态、系统文档和更新日志。

## 回退

- 前端可回退为不显示投放入口；后台未处理任务不会由前端继续创建。
- 新表和兼容字段不影响旧读取；旧 `mascot_ad_deliveries` 记录按默认值保持可读。
- 本轮仅本地实施，不更新服务器或 GitHub。
