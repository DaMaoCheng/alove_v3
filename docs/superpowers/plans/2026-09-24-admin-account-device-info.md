# 账号管理设备信息实施方案

## 目标

- 游客会话展开详情显示最近一次访问设备。
- 正式账号展开详情显示最后一次成功登录设备；普通页面访问不得覆盖该值。
- 只展示设备类型、操作系统和浏览器，不推测具体手机型号。
- 复用用户反馈已经采用的 `User-Agent` 请求信息与账号管理现有详情行样式。

## 实现范围

1. 数据库为 `users` 增加 `last_login_user_agent`，为 `guest_sessions` 增加 `last_user_agent`，迁移保持幂等。
2. 请求访问上下文统一读取并限制 `User-Agent` 长度。
3. 登录成功签发正式会话时更新账号字段；游客创建、恢复或继续使用会话时更新游客字段。
4. 后台账号与游客接口返回经过统一规则归纳的设备标签。
5. 账号展开详情显示“最后登录设备”，游客展开详情显示“最近访问设备”。

## 验收标准

- iPhone Safari 显示为“手机 · iOS · Safari”。
- Android Chrome、Windows Edge 等常见请求能归纳到对应设备、系统和浏览器。
- 正式账号普通鉴权请求不会覆盖最后登录设备。
- 游客后续使用不同设备访问时更新最近访问设备。
- 没有历史数据的记录显示“-”。
- 账号管理现有筛选、分页、来源页面、IP、对话查看与页面样式保持不变。

## 回退点

- 页面可停止读取新增字段，数据库新增的可空字段不会影响旧代码。
- 数据采集失败时只缺少设备展示，不阻断登录、游客会话或聊天。
