# 数据 API 管理（本地）

## 目标与范围
管理员在独立页面创建只读报告 Token。先弹窗选择权限、站点与有效期，确认后生成；完整密钥仅显示一次。提供可实际调用的账号、游客、会话、消息查询接口及字段说明。此次不发布线上。

## 实施
1. 新增独立 reporting token service 和表，随机凭证仅存哈希，支持撤销/过期/使用统计；管理写接口复用管理员权限校验。
2. 新增 reporting 只读路由及查询 service，逐请求检查 scopes 和站点归属，分页读取；复用既有消息映射，IP标注为最近记录值，不冒充逐条消息IP。
3. 后台新增数据 API 导航与页面，复用后台列表、按钮和弹窗样式。权限与站点选择后才允许创建，关闭结果后清除内存中的密钥；提供 Base URL、请求头和调用示例。
4. 增加HTTP/DB权限及功能自检，实际本地页面验证，独立安全复查，补充日志与接口文档。

## 验收
- 无凭证、错误、过期、撤销凭证拒绝；普通用户不能管理Token。
- 缺少权限不能调用对应接口，站点范围覆盖列表及直接ID查询。
- 列表/日志不包含完整Token，数据库不含原始Token，查询接口不能改业务数据。
- 账号、游客和对话消息有明确字段及分页；受保护媒体不被改成公开文件。
- 创建/复制/取消/撤销/切页不串状态，既有后台功能和样式正常。

## 回退
新增模块可独立移除入口；数据库只新增表，不改变现有聊天及账号表数据。不增加会话IP快照或修改聊天写入链路。
