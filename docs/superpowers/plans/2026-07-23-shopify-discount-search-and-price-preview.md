# Shopify 折扣码搜索、规则同步与商品折后价预览实施计划

状态：`Completed locally / Not deployed`

关联计划：[`2026-07-21-role-scoped-discount-offers.md`](./2026-07-21-role-scoped-discount-offers.md)

## 1. 目标

- 后台新增/编辑折扣码时，先选择站点，再按输入内容实时搜索该站点 Shopify 中的真实折扣码。
- 管理员必须从 Shopify 候选项中选择；保存时服务端再次精确读取，不能信任前端提交的折扣类型、金额、门槛或有效期。
- 折扣码、Shopify 优惠说明、类型、数值、门槛和有效期由 Shopify 自动填充；归属、网红账号、Alove 启用状态和后台备注继续由 Alove 管理。
- 商品详情选中折扣码后，只在规则可以确定计算时显示预计折后价；最终金额继续以 Shopify Checkout 为准。
- 继续复用站点现有 Shopify Admin Token，不新增站点管理输入字段。

## 2. 数据与接口

### 数据库

在现有 `discount_codes` 表幂等增加：

- `shopify_discount_id`：Shopify DiscountNode ID。
- `shopify_discount_type`：`percentage`、`fixed_amount`、`free_shipping`、`bxgy`、`app` 或 `unsupported`。
- `shopify_status`：Shopify 当前状态。
- `shopify_rule_json`：经过后端白名单归一化的规则快照。
- `shopify_synced_at`：最后一次成功读取时间。

旧记录保持可读；编辑保存时必须重新从 Shopify 选择并同步后，才能更新为新的可信快照。

### 后端

- 新增独立 Shopify 折扣目录服务，负责候选搜索、精确读取、字段白名单和错误映射。
- 规则快照只信任 15 分钟；候选不先受旧时间边界排除。过期或 scheduled 到点时按站点/code 合并并发刷新，写回带乐观锁，失败不返回旧优惠并短暂冷却。
- 管理员搜索接口只接受 `siteId` 与有限长度 `query`，从服务端读取站点 Token。
- 搜索要求 `admin:promotions:write`，并使用 15 秒同查询缓存与管理员级频率限制保护 Shopify 配额。
- 创建/编辑接口只接收 `siteId`、选中的 `code` 和 Alove 运营字段；保存事务前重新读取 Shopify。
- 角色折扣资格 DTO 增加安全的 `pricingPreview`，不返回后台备注、原始 GraphQL 或完整 Shopify JSON。

## 3. 后台交互

- 站点字段放在折扣码搜索前；切换站点立即清空候选和已选 Shopify 规则。
- 输入至少 2 个字符，300ms 防抖；旧请求不能覆盖新输入结果。
- 下拉项展示：折扣码、优惠摘要、类型/数值、状态和有效期。
- 选择候选后显示只读规则摘要。
- 删除手工“优惠说明”和手工“有效期模式/开始/结束”输入；这些字段改由 Shopify 同步。
- 保留：归属、网红账号、后台备注、Alove 启用状态。
- 未选择真实候选、Shopify 查询失败、折扣不存在或状态不可用时明确提示并拒绝保存。

## 4. 商品详情价格预览

- 百分比折扣且当前商品规则可确定适用：按当前已选变体价格计算。
- 固定金额且 `appliesOnEachItem=true`、币种一致且规则可确定适用：按当前已选变体价格计算，最低为 0。
- 满额/满件门槛未满足、整单分摊固定金额、指定客户、免运费、买 X 送 Y、App 折扣和无法确认适用范围：只显示 Shopify 优惠说明，不改商品价格。
- 选择其他码、取消选择、切换尺码/商品或折扣列表刷新时重新计算或清空预览。
- 折后价标记为“预计折后价”，不能显示为已成功应用。

## 5. 验证与回退

### 验证

- 数据库迁移在空库和已有库重复运行。
- 搜索覆盖：无 Token、无权限、少于 2 字符、无结果、大小写、网络失败、旧响应覆盖和跨站点。
- 保存覆盖：伪造 code、篡改规则、折扣删除/停用、重复 code、creator 跨站和旧记录兼容。
- 商品详情覆盖：百分比、固定金额、门槛、币种不一致、复杂类型、切换/取消、Search/Kitshop/Chat 共用面板和游客隔离。
- 运行语法、专项自检、真实本地 HTTP、真实浏览器、相邻折扣码 CRUD、产品详情和完整部署门禁。
- 核心运营与商品链路完成后进行架构/数据安全/异常边界三类互评。

### 回退

- 前端可回退为原手工登记弹窗。
- 新数据库字段为可空字段，旧读取链路仍可继续使用 `offer_description` 和原有效期字段。
- 商品详情无法取得可信规则时自动回退为仅展示折扣码，不改变商品价格。
