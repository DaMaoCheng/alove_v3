## Important Data Rules

Discover card fields:

- Name, avatar, and short role title are treated as created-time card identity fields.
- Discover rendering does not call AI and does not regenerate those fields.
- Chat count is intentionally dynamic:
  - grouped by `chat_sessions.character_id`
  - counts only `chat_messages.sender_type = 'user'`
  - requires `chat_messages.delivery_status = 'sent'`
  - ignores AI messages
- Rating still uses `metrics_json.ratingLabel`.
- Favorite/bookmark remains undecided.

Note: admin editing still has broader character-edit capability. If strict immutability is required, lock `name`, `avatar_url`, and `role_title` in the admin update path.
