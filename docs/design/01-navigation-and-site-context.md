# 01. 路由与站点上下文

## 当前路由模型

`Current`：用户侧站点路由以 `/:siteSlug/...` 作为公开入口，例如登录、注册、Discover、Search、Create 与 Chat。未带站点前缀的入口会调用站点解析能力后进入一个站点路径。

`Current`：公开路径不再由前端硬编码站点白名单决定。只要 slug 语法有效、不是 `admin`、`api`、`login` 等保留路径，并且服务端能解析为 active 站点，即可作为新站点路径；新增站点不应要求再次修改前端路由代码。语法有效但不存在/停用的显式路径会先按现有访客分流解析真实 active 站点，再保留页面类型和 query 替换为真实路径，不能继续携带假 slug 注册到默认站点。

`Current`：显式 URL 路径是本次访问的最高优先站点信号。用户打开 `https://alove.fans/<siteSlug>` 或其子路径时，该路径确定当前站点上下文；IP/地区只用于没有显式站点路径的入口解析，不能覆盖路径。

`Current`：已登录的普通用户只能使用自己的用户归属站点。访问其他站点路径时，系统将其送回所属站点；管理员可管理全部站点。

## 注册与邀请码

`Current`：注册由当前路径的站点上下文决定用户归属站点，并自动激活该站点前台。

`Current`：邀请码不会把用户从当前路径改分流到邀请人的站点。邀请码仅在当前站点内有效；归属不同站点的邀请码应被拒绝并要求用户使用正确的站点入口。

`Current`：外部独立站的按钮应使用完整站点路径，而不是只链接根域名。若期望落到指定前台，可附带 `chat?agent=<characterId>`；站点启用游客聊天时，未登录用户可先进入受限前台聊天，否则进入同站点认证入口。

## 认证后的去向

`Current`：登录/注册成功后，用户进入自己的站点上下文和可用联系人；旧账号不会因为从另一站点路径登录而被迁移站点。

`Current`：未登录游客完成同站点注册或登录后回到被承接的前台会话；已有账号跨站点登录不改变账号 `site_id`，也不迁移游客会话。

## 游客站点上下文

`Current`：游客入口携带并持续保留显式站点上下文；guest session 冻结站点和前台，IP/默认站点不能覆盖。注册或同站点登录完成后把游客会话转移到该账号，而不是重新分流。

`Current`：任何站点入口的刷新、登录、注册和受限操作引导都不得无故切换到其他站点。只有用户手动更改 URL、管理员变更归属或已记录的确定性迁移规则才可改变归属。

## 站点公开品牌上下文

`Current`：站点名称、slug、公开网站链接、Logo 和可公开的能力状态属于同一份站点品牌上下文。用户侧只能通过公开白名单接口读取 `siteId`、`name`、`slug`、`siteUrl`、`logoUrl`，以及不含密钥内容的 `hasProductAccessToken` 布尔值；不能读取商品 token、Shopify Admin 地址、地区绑定或后台备注。

`Current`：站点 Logo 的确定性优先级为：后台显式 `logoUrl` → 站点公开网站 favicon → 商品公开 URL favicon →通用 globe。若后台尚未填写网站链接，服务端可从同站点 active 可信商品缓存的公开商品 URL 推导独立站 origin；不得从 Shopify Admin 域名推导用户品牌。

`Current`：Kitshop、聊天商品详情和后续站点认证入口复用当前站点品牌上下文。历史商品消息只保存稳定站点标识和商品快照，打开详情时重新读取当前品牌，因此管理员更换 Logo 后不需要批量改写历史聊天消息。

`Current`：上述规则按当前路径解析出的站点执行，不对任何具体 slug 写死。未来新增站点只要完成 active 站点、品牌和对应能力配置，就自动使用同一套路由、品牌与能力判断；未配置的能力不得从其他站点继承或回退。

## 站点默认语言

`Current locally`（尚未部署）：`sites.default_language` 是当前站点用户端页面和新聊天会话的默认语言来源。公开 branding 与无显式路径访客解析只返回标准化后的 `{ code, label, uiCode }`，不暴露任何后台私有配置；前端不得再根据 slug 写死语言。

`Current locally`（尚未部署）：当前用户端 UI 翻译包确定性支持 English 与 Chinese (Mandarin)。站点配置为其他已识别语言时，AI 可以使用该语言，但页面固定文案暂回退 English，直到对应翻译包通过完整验收。商品标题、角色名称和独立站返回的业务内容保留原文，不做浏览器端自动翻译。

`Current locally`（尚未部署）：当前显式路径解析出的 active 站点决定页面语言；切换路径、刷新或后台更新当前站点后必须同步刷新 language context 与 `<html lang>`。同一浏览器同时打开不同站点时，各页面按各自路径解析，不能互相污染。
