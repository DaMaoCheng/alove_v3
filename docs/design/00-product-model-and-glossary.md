# 00. 产品模型与术语

## 产品模型

`Current`：AIOVE 是一个共用后端的多站点 AI 陪伴与足球消费辅助产品。前台提供角色聊天、语音、商品推荐、知识库和用户记忆；后台管理站点、角色、前台、活动、知识库和账号。

`Current`：站点是业务归属单位，不是国家、语言或单个独立站的别名。一个站点拥有稳定 slug、默认前台、商品源、运营配置和用户归属；地区与语言只可作为站点解析或展示配置。

## 核心术语

| 术语 | 定义 | 状态 |
| --- | --- | --- |
| Site | 独立运营单元，以稳定 `site_id` 作为内部身份、`slug` 作为用户路径。 | Current |
| Site context | 一次请求/页面所解析出的站点上下文；用于页面、角色、商品和注册归属。 | Current |
| User site | 已注册用户唯一的业务归属站点。 | Current |
| Mascot | 站点默认前台角色；是普通 AI 角色记录，注册后自动激活并受保护。 | Current |
| Creator character | 绑定创作者账号、仅在所属站点展示的角色。 | Current |
| Common character | 不绑定站点、可按可见性规则跨站点展示的角色。 | Current |
| Activation | 用户与角色建立可聊天联系的记录。 | Current |
| Chat session | 一个用户与一个角色的会话容器，承载消息与上下文。 | Current |
| Memory | 从聊天中提取的长期用户偏好、事实或互动信息；不得把模型推测当成事实。 | Current |
| Promotion campaign | 后台配置的站点级促销投放规则，可携带商品和折扣码。 | Current |
| Benefit | 面向用户的权益资格；未来可分为站点、创作者和忠诚度三类。 | Approved direction |
| External account | 用户在外部商城或合作方的经过验证的账号身份。 | Approved direction |

## 统一原则

- `Current`：内部关系使用稳定 ID，不以站点展示名、URL 文案或角色昵称作为业务判断依据。
- `Current`：权限、路由、站点归属、活动资格和状态流转必须由后端的确定性规则决定，不能交给模型或前端猜测。
- `Approved direction`：新增独立站时只新增站点实例和运营配置；不得为某一个站点写专属业务分支，除非有明确且记录在案的例外规则。
