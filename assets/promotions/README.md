# Promotion assets

- `pj-black-friday-2026.png`: original campaign poster supplied by the project owner for the PJ widget. Display without cropping or rewriting the offer text.
- `pj-gift.svg`: reproduces the supplied TMS product page's actual launcher: native `🎁` rendered with its emoji font stack, a -9° resting tilt and red `!` badge. The reference's separate flat Twemoji asset was not the visible product launcher and is no longer used here. The SVG keeps the existing configurable image interface; movement remains implemented by the widget. Native emoji artwork varies by operating system, as it does on the reference page.

These assets do not enable or publish a campaign. Configuration and publication are controlled separately.
